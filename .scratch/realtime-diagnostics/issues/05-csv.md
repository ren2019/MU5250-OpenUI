# 05: 诊断记录 CSV 导出

**What to build:** 用户将当前时间窗口中的设备指标、所选载波历史和事件导出为可解释的 CSV，供进一步分析。

**Blocked by:** 03 — 温度与 CPU 趋势对照；04 — 变化事件与定位回看.

**Status:** ready-for-agent

依据：已确认的实时诊断规格与 Prototype A「时间轴对照」；入口见[任务索引](../README.md)。

- [ ] 通过页面下载当前窗口数据，包含七项指标中实际可用的记录与事件，不导出窗口外或无关载波数据。
- [ ] 记录包含实际时间、指标、值、单位、来源、载波身份及质量；事件使用可区分的记录类型。
- [ ] 缺失值留空而非零；数值与页面单位一致，旧样本不伪装成新读数。
- [ ] 导出瞬间固定数据范围，即使采集仍在进行也保证文件内部一致。
- [ ] 模拟模式的导出明确标记模拟；不包含令牌、密码或其他认证信息。
- [ ] 从页面下载并解析文件，验证窗口、载波、七项指标、事件、空值、单位和时间与可见状态一致；既有回归和构建/lint 通过。
