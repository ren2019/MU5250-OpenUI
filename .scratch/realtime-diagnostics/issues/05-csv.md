# 05: 诊断记录 CSV 导出

**What to build:** 用户将当前时间窗口中的设备指标、所选载波历史和事件导出为可解释的 CSV，供进一步分析。

**Blocked by:** 03 — 温度与 CPU 趋势对照；04 — 变化事件与定位回看.

**Status:** implemented — 已集成；复合验收项按实际证据勾选

依据：已确认的实时诊断规格与 Prototype A「时间轴对照」；入口见[任务索引](../README.md)。

- [x] 通过页面下载当前窗口数据，包含七项指标中实际可用的记录与事件，不导出窗口外或无关载波数据。
- [x] 记录包含实际时间、指标、值、单位、来源、载波身份及质量；事件使用可区分的记录类型。
- [x] 缺失值留空而非零；数值与页面单位一致，旧样本不伪装成新读数。
- [x] 导出瞬间固定数据范围，即使采集仍在进行也保证文件内部一致。
- [x] 模拟模式的导出明确标记模拟；不包含令牌、密码或其他认证信息。
- [x] 从页面下载并解析文件，验证窗口、载波、七项指标、事件、空值、单位和时间与可见状态一致；既有回归和构建/lint 通过。

集成验证（2026-09-18）：实际点击页面导出，解析下载文件 422 行，含七类指标、10 条事件，载波仅 PCI 312；时间在窗口内、无效值为空、下行 8 Mbps、每行 SIMULATED、无 demo-token。自动测试另覆盖固定窗口快照、源时间和文本转义。 统一代码检查与待验边界见[验收记录](../../../../docs/REALTIME-DIAGNOSTICS-ACCEPTANCE.md)。
