# 03: 温度与 CPU 趋势对照

**What to build:** 用户在共同时间轴查看基带温度和 CPU 使用率，比较温升、设备负载与吞吐量变化。

**Blocked by:** 01 — 实时速率时间轴.

**Status:** ready-for-agent

依据：已确认的实时诊断规格与 Prototype A「时间轴对照」；入口见[任务索引](../README.md)。

- [ ] 复用已有 CPU 和详细温度能力；展示基带温度 °C 和 CPU 百分比，不把 CPU 温度冒充基带温度。
- [ ] 温度目标 10 秒、CPU 目标 3 秒更新，但真实新鲜度以源契约为准；仅在必要时补充温度来源元信息。
- [ ] 不支持、单源失败和过期分别可见，其他源仍可正常更新；重复缓存不增加虚假样本。
- [ ] 接入共同窗口、光标和暂停行为；不同采样频率下保留真实时间，不让温度曲线呈现伪造的高频更新。
- [ ] 温升与掉速仅提示相关线索，不显示未经证实的热降频结论。
- [ ] 页面验收覆盖多采样周期、无基带传感器、单源失败/恢复和光标有效期；既有回归和构建/lint 通过。

实施记录：已接入独立 10 秒基带传感器采集及共享 dashboard CPU 数据；温度接口补充 modem 专属新鲜度和支持状态。旧代理无元信息时使用明确的接收时间，不推断设备采样时间。缺失传感器不使用 CPU 温度替代；暂停后拒绝重放暂停期间缓存读数。构建、lint、既有 11 项前端测试、50 项 Rust 测试通过，React Doctor 56 分（无新增告警）。页面级多周期、单源失败及恢复验收留待集成；真机核验未执行。
