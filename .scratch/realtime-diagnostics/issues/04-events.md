# 04: 变化事件与定位回看

**What to build:** 用户在 A 方案右侧时间线看到状态变化，并点击事件同步查看对应时刻的全部已接入指标。

**Blocked by:** 02 — 无线质量与载波历史.

**Status:** implemented — 已集成；复合验收项按实际证据勾选

依据：已确认的实时诊断规格与 Prototype A「时间轴对照」；入口见[任务索引](../README.md)。

- [x] 展示观测到的制式、小区/PCI、载波集合、已知连接状态和采集失败/恢复变化；标明观测时间。
- [x] 首次有效采样建立基线，不报变化；重复缓存不重复生成事件。
- [x] 只比较连续有效且可比的状态，缺失期间不推断无线侧发生的中间变化，不将采集失败直接称为断网。
- [x] 点击事件定位公共光标，各曲线按自己的实际采样时间和有效期显示；可回到最新。
- [x] 事件按 60 分钟保留窗口淘汰；暂停期间不补造事件，窄屏时间线置于曲线之后。
- [x] 不依赖温度/CPU 任务，已有曲线即可完整演示；未来接入指标自动参与同一光标定位。
- [ ] 页面验收覆盖首次基线、缓存重复、真实状态差异、缺口恢复、事件点击及淘汰；既有回归和构建/lint 通过。

集成验证（2026-09-18）：浏览器已检查初始无事件、小区与载波变更、点击联动、HTTP 失败恢复不伪造小区事件；重复缓存、间断重建基线和淘汰由自动测试覆盖。 统一代码检查与待验边界见[验收记录](../../../../docs/REALTIME-DIAGNOSTICS-ACCEPTANCE.md)。
