# 06: 完整诊断流程验收

**What to build:** 用户在桌面和手机完成观察、事件回看与导出的完整诊断流程；记录模拟验收和已授权真机只读核验各自的证据。

**Blocked by:** 05 — 诊断记录 CSV 导出.

**Status:** ready-for-agent

依据：已确认的实时诊断规格与 Prototype A「时间轴对照」；入口见[任务索引](../README.md)。

- [ ] 依据 Prototype A 核对七条曲线、共同时间轴、侧边事件线；正式入口不暴露原型方案和场景控件。
- [ ] 桌面及 390 像素窄屏、浅深主题可读且无横向页面溢出；键盘、触摸能够定位、暂停和返回最新。
- [ ] 完整流程涵盖窗口、载波、不同源采样周期、缺口、事件回看和 CSV；此前各票仍各自完成测试，不将基础测试推迟到本票。
- [ ] 重复进出页面、后台恢复及长窗口验证无重复诊断请求或卸载后追加；构建、lint 和既有测试通过。
- [ ] 仅在可用且已获授权的设备上只读核对单位、字段支持、新鲜度和连续采集，不切网、锁频、改温控、重启或部署。
- [ ] 记录真实设备型号/固件、核验项目及观察结果；无法完成真机核验时明确留为未完成验收，不能用模拟通过替代。
- [ ] 交付验收记录，区分代码检查、模拟页面结果及真机结果，不将相关变化声称为已确认根因。
