# 03: 温度与 CPU 趋势对照

**What to build:** 用户在共同时间轴查看基带温度和 CPU 使用率，比较温升、设备负载与吞吐量变化。

**Blocked by:** 01 — 实时速率时间轴.

**Status:** implemented — 已集成；复合验收项按实际证据勾选

依据：已确认的实时诊断规格与 Prototype A「时间轴对照」；入口见[任务索引](../README.md)。

- [x] 复用已有 CPU 和详细温度能力；展示基带温度 °C 和 CPU 百分比，不把 CPU 温度冒充基带温度。
- [x] 温度目标 10 秒、CPU 目标 3 秒更新，但真实新鲜度以源契约为准；仅在必要时补充温度来源元信息。
- [x] 不支持、单源失败和过期分别可见，其他源仍可正常更新；重复缓存不增加虚假样本。
- [x] 接入共同窗口、光标和暂停行为；不同采样频率下保留真实时间，不让温度曲线呈现伪造的高频更新。
- [x] 温升与掉速仅提示相关线索，不显示未经证实的热降频结论。
- [ ] 页面验收覆盖多采样周期、无基带传感器、单源失败/恢复和光标有效期；既有回归和构建/lint 通过。


集成验证（2026-09-18）：浏览器已检查 65°C 基带温度、25% CPU、独立采样时刻、不支持基带传感器时其他源继续更新；更多热源失败/恢复页面场景待 06。 统一代码检查与待验边界见[验收记录](../../../../docs/REALTIME-DIAGNOSTICS-ACCEPTANCE.md)。
