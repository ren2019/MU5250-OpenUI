## 模拟页面主流程

由主实施任务通过 CUA 操作真实页面，使用隔离的本机 HTTP mock（[::1]:9090）和 Vite（[::1]:8090），无真实设备流量。以下为实际观察，不是仅由源码推断：

- 正式信号页诊断入口显示七条纵向曲线及共同时间轴，未使用原型查询参数或场景控件。
- 原始 1,000,000/250,000 bytes/s 显示为下行 8、上行 2 Mbps；零流量显示有效 0.0。
- 暂停后切换 mock 响应，读数及窗口仍冻结；恢复后缺失的下行留空，上行维持有效。HTTP 503 显示刷新失败与上次读数；恢复后重新采集。图中暂停、缺失和失败区间均留白。
- 选择 5 分钟窗口；时间滑块 ArrowLeft 进入回看，读数保留其质量状态。
- 选择实际 NR PCI 801 时无线指标为 SINR 23.5 dB、RSRP -77 dBm、RSRQ -9.2 dB；WAN 仍为设备整体 8/2 Mbps。
- 载波由 801 变为 802 后，801 保持为“已消失·历史”，无线当前读数缺失，新载波作为另一选项出现，没有静默替换。
- 基带温度 65°C、CPU 25%，显示各自不同的源采样时间。无基带传感器显示“不支持”，WAN 和 CPU 继续有效，没有用 CPU 温度替代。
- 无线源 1 秒 TTL 在 3 秒页面轮询间隔内到期时标为过期，不把缓存值持续称作实时有效。
- 初始基线无变化事件；小区和载波集合变化生成事件；点击后全部曲线按不晚于光标的自身样本定位，温度使用较早样本。
- HTTP 失败/恢复分别记录来源事件，基带温度保持有效；跨缺口没有虚构小区变化。
- 390×844 响应式布局中页面宽度与视口同为 390，浅深主题曲线及控件可读；指针点击可以选定历史时间。这是窄屏模拟，不是物理手机触摸测试。
- 实际点击 CSV 导出后取得并解析下载文件：422 行、七类指标、10 条事件；只有所选 PCI 312，时间均在窗口内，下行为 8 Mbps，无效值为空，全部行带 SIMULATED 且未包含 demo-token。工具下载事件等待曾超时，但实际磁盘文件存在并通过解析；验收依据是文件内容。

## 待完成的验收

- 页面退出后超过 12 秒仅共享 dashboard 请求继续，温度请求为零；重新进入时 WAN/无线/CPU 历史及事件为空，温度新响应立即加入。重新进入后精确 12 秒内观测到 dashboard 4 次、温度 2 次请求，与 3 秒/10 秒周期（含窗口边界）一致，没有观察到重复请求。这覆盖一次进出，仍需后台恢复和多次进出/长窗口页面复验；自动轮询与可控时间测试已覆盖底层行为。
- 补齐载波重排/恢复等完整页面场景；目前核心页面场景及相应模型行为已覆盖。复审修复后已从页面验证温度 HTTP 503：出现一条基带温度采集不可用事件；恢复正常响应后出现一条恢复事件，其他指标持续更新。再次点击导出并解析实际下载 CSV，确认同时包含 thermal 的 failure/recovery 事件。
- 物理手机触摸操作尚未验证，不能将窄屏指针操作称为真机触摸验收。曾尝试浏览器触摸模拟，但当前内置浏览器不支持该命令；未据此声称触摸测试通过。
- 真机只读核验未执行：本次未取得可用设备的型号/固件、字段支持、新鲜度及连续采集观察记录。后续仅在设备可用且获授权后进行只读核对；不切网、锁频、改温控、重启、部署或人为制造故障。

因此本记录不宣称上线验收完成，不将信号、温度与速率的同时变化称为已确认根因。
