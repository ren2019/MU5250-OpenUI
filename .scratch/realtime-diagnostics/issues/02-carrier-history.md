# 02: 无线质量与载波历史

**What to build:** 用户选择实际存在的 LTE/NR 载波，在同一时间轴对照 SINR、RSRP、RSRQ 和设备吞吐量，并可回看消失载波的历史。

**Blocked by:** 01 — 实时速率时间轴.

**Status:** ready-for-agent

依据：已确认的实时诊断规格与 Prototype A「时间轴对照」；入口见[任务索引](../README.md)。

- [ ] 列出实际 LTE/NR PCC/SCC 及频段、PCI 等上下文，不使用硬编码载波。
- [ ] 无线质量使用正确的 dB/dBm 单位，与速率曲线联动；不同采样时间独立显示，不从未来取值或跨缺口插值。
- [ ] 用制式、角色、频段、频点、PCI 等可用信息区分身份，不仅依赖数组位置或 PCI；重排数组不制造身份切换。
- [ ] 载波身份变化时分段；消失后停止追加并保留历史选择，不静默替换其他载波。
- [ ] 切换载波只影响无线指标，WAN 速率仍明确是设备整体吞吐量。
- [ ] 页面验收覆盖多载波、字段缺失、身份变化、消失/恢复、数组重排及历史联动；既有回归和构建/lint 通过。
